# Model Library

> 以下为 Ollama 生态中常见、实用的模型类型与选型建议。

## 1. 通用对话模型

| 模型 | 特点 | 推荐场景 |
|---|---|---|
| `llama3.2` | 通用性好、生态成熟 | 通用聊天、问答、总结 |
| `mistral` | 响应快、效果稳定 | 低延迟助手、轻量服务 |
| `phi3` | 小参数高性价比 | 资源受限设备 |

## 2. 代码模型

| 模型 | 特点 | 推荐场景 |
|---|---|---|
| `codellama` | 代码生成与解释能力强 | 代码补全、重构建议 |
| `deepseek-coder`（若可用） | 推理与代码混合任务表现好 | 复杂开发助手 |

## 3. Embedding 模型

| 模型 | 用途 |
|---|---|
| `nomic-embed-text` | 文本向量化、RAG 检索 |

## 4. 多模态模型（如版本可用）

支持图像输入的模型可用于图像问答、OCR 辅助、UI 解析。

## 5. 选型原则

1. 先按硬件资源筛选（显存/内存）。
2. 再按任务类型筛选（对话/代码/embedding）。
3. 用同一测试集做 A/B 评估（准确率、延迟、成本）。

## 6. 常用命令

```bash
# 查看本地模型
ollama list

# 拉取模型
ollama pull llama3.2

# 运行模型
ollama run llama3.2
```

## 7. 生产建议

- 在线服务使用固定模型版本，避免“latest”漂移。
- 建立回归测试（提示词 + 期望输出片段）。
- 高并发场景单独部署 embedding 与 chat 模型。
