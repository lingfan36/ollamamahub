REST API Reference

Ollama exposes a REST API on port 11434 for interacting with language models programmatically.

Base URL: http://localhost:11434

Generate a completion

POST /api/generate

Generate a response for a given prompt with a specified model. Streams by default.

Parameters

NameTypeRequiredDescription
modelstringYesModel name (e.g., llama3.2)
promptstringYesThe prompt to generate a response for
streambooleanNoIf false, returns a single JSON object (default: true)
systemstringNoSystem message override
optionsobjectNoAdditional model parameters — temperature, top_p, seed, etc.
contextarrayNoContext array returned from a previous request for conversation continuity
imagesarrayNoBase64-encoded images for multimodal models
 
curl http://localhost:11434/api/generate \
  -d '{
    "model": "llama3.2",
    "prompt": "Why is the sky blue?",
    "stream": false
  }'
{
  "model": "llama3.2",
  "created_at": "2024-08-04T08:52:19.385406455Z",
  "response": "The sky appears blue due to a phenomenon called Rayleigh scattering...",
  "done": true,
  "total_duration": 5589157167,
  "prompt_eval_count": 46,
  "eval_count": 113
}

Generate a chat completion

POST /api/chat

Generate the next message in a chat with a model. Supports multi-turn conversations and tool/function calling.

Parameters

NameTypeRequiredDescription
modelstringYesModel name
messagesarrayYesArray of {role, content} message objects
streambooleanNoStream the response (default: true)
toolsarrayNoTools available for the model to call (function calling)
optionsobjectNoModel parameters (same as generate)
 
curl http://localhost:11434/api/chat \
  -d '{
    "model": "llama3.2",
    "messages": [
      { "role": "system", "content": "You are a helpful assistant." },
      { "role": "user", "content": "Why is the sky blue?" }
    ],
    "stream": false
  }'

Generate embeddings

POST /api/embeddings

Generate embeddings from a model for a given prompt. Useful for RAG pipelines and semantic search.

curl http://localhost:11434/api/embeddings \
  -d '{
    "model": "nomic-embed-text",
    "prompt": "The sky is blue because of Rayleigh scattering"
  }'

Model management

List local models

GET /api/tags 
curl http://localhost:11434/api/tags

Pull a model

POST /api/pull 
curl http://localhost:11434/api/pull \
  -d '{ "name": "llama3.2", "stream": false }'

Delete a model

DELETE /api/delete 
curl -X DELETE http://localhost:11434/api/delete \
  -d '{ "name": "llama3.2" }'

Show model info

POST /api/show 
curl http://localhost:11434/api/show \
  -d '{ "name": "llama3.2" }'

Python Library

Install the official Python library:

pip install ollama

Chat

import ollama

response = ollama.chat(
    model='llama3.2',
    messages=[{'role': 'user', 'content': 'Why is the sky blue?'}]
)
print(response['message']['content'])

Streaming

import ollama

for chunk in ollama.chat(
    model='llama3.2',
    messages=[{'role': 'user', 'content': 'Tell me a story'}],
    stream=True
):
    print(chunk['message']['content'], end='', flush=True)

Async client

import asyncio
import ollama

async def main():
    client = ollama.AsyncClient()
    response = await client.chat(
        model='llama3.2',
        messages=[{'role': 'user', 'content': 'Hello!'}]
    )
    print(response['message']['content'])

asyncio.run(main())

JavaScript / TypeScript Library

Install the official JavaScript library:

npm install ollama

Chat (Node.js / browser)

import ollama from 'ollama'

const response = await ollama.chat({
  model: 'llama3.2',
  messages: [{ role: 'user', content: 'Why is the sky blue?' }]
})
console.log(response.message.content)

Streaming

import ollama from 'ollama'

const stream = await ollama.chat({
  model: 'llama3.2',
  messages: [{ role: 'user', content: 'Tell me a story' }],
  stream: true
})

for await (const chunk of stream) {
  process.stdout.write(chunk.message.content)
}

OpenAI Compatibility

Ollama is compatible with the OpenAI Chat Completions API, allowing you to use OpenAI SDKs with a local server:

from openai import OpenAI

client = OpenAI(
    base_url='http://localhost:11434/v1',
    api_key='ollama',  # required but unused
)

response = client.chat.completions.create(
    model='llama3.2',
    messages=[{'role': 'user', 'content': 'Why is the sky blue?'}]
)
print(response.choices[0].message.content)

Supported OpenAI endpoints: /v1/chat/completions, /v1/completions, /v1/embeddings, /v1/models.
