Configuration

Ollama is configured via environment variables. These can be set at the system level, via a .env file, or through systemd overrides on Linux.

Environment Variables

All Ollama configuration is done through environment variables. Here is the full reference:

Variable Default Description
OLLAMA_HOST 127.0.0.1:11434 The host and port Ollama listens on
OLLAMA_MODELS ~/.ollama/models Directory where models are stored
OLLAMA_KEEP_ALIVE 5m How long models stay loaded in memory
OLLAMA_NUM_PARALLEL 1 Maximum number of parallel requests
OLLAMA_MAX_LOADED_MODELS 1 Max number of models loaded simultaneously
OLLAMA_ORIGINS (empty) Comma-separated list of allowed CORS origins
OLLAMA_DEBUG 0 Set to 1 for verbose debug logging
OLLAMA_FLASH_ATTENTION 0 Enable Flash Attention for faster inference
HTTPS_PROXY (empty) Proxy for model downloads

Linux — systemd Override

On Linux, Ollama runs as a systemd service. The recommended way to set environment variables is via a systemd drop-in file:

sudo systemctl edit ollama

This opens an editor. Add your variables under [Service]:

[Service]
Environment="OLLAMA_HOST=0.0.0.0"
Environment="OLLAMA_MODELS=/mnt/models"
Environment="OLLAMA_KEEP_ALIVE=10m"

Then reload and restart:

sudo systemctl daemon-reload
sudo systemctl restart ollama

macOS

On macOS, Ollama runs as a menu bar application. Set environment variables with launchctl:

launchctl setenv OLLAMA_HOST "0.0.0.0"
launchctl setenv OLLAMA_KEEP_ALIVE "10m"

Then restart the Ollama app from the menu bar.

Windows

On Windows, set environment variables through System Properties → Environment Variables or via PowerShell:

[System.Environment]::SetEnvironmentVariable('OLLAMA_HOST', '0.0.0.0', 'User')
[System.Environment]::SetEnvironmentVariable('OLLAMA_MODELS', 'D:\models', 'User')

After setting variables, restart Ollama from the system tray.

Docker

When running Ollama in Docker, pass environment variables with the -e flag:

docker run -d \
  -e OLLAMA_HOST=0.0.0.0 \
  -e OLLAMA_KEEP_ALIVE=10m \
  -p 11434:11434 \
  -v ollama:/root/.ollama \
  ollama/ollama

CORS Configuration

To allow browser-based clients to call the Ollama API, set OLLAMA_ORIGINS:

# Allow all origins (development only)
OLLAMA_ORIGINS=*

# Allow specific origins
OLLAMA_ORIGINS=https://myapp.com,http://localhost:3000

Security note: Never use OLLAMA_ORIGINS=* in production. Always restrict to your specific domain(s).

Proxy Settings

If you're behind a corporate proxy and model downloads are failing, set the standard proxy environment variables:

HTTPS_PROXY=http://proxy.corp.example.com:8080
HTTP_PROXY=http://proxy.corp.example.com:8080
NO_PROXY=localhost,127.0.0.1
