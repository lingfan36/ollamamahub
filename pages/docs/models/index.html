Model Library

Browse, pull, and manage models. Ollama supports hundreds of open-source LLMs — from compact 1B models to massive 405B ones.

Popular Models

Use ollama pull <name> or ollama run <name> to get any model:

llama3.2 3B / 8B

Meta's latest Llama — best overall for general tasks

mistral 7B

Fast, capable — great balance of speed and quality

codellama 7B / 13B / 34B

Code generation, completion, and explanation

phi3 3.8B / 14B

Microsoft Phi-3 — excellent for resource-constrained devices

gemma2 2B / 9B / 27B

Google Gemma 2 — strong multilingual performance

deepseek-r1 1.5B–671B

DeepSeek R1 reasoning model — top math and coding

qwen2.5 0.5B–72B

Model Tags & Quantization

Models are versioned with tags. Append a tag after the model name with a colon:

ollama pull llama3.2:3b          # 3B parameter variant
ollama pull llama3.2:8b-q4_K_M  # 8B with Q4_K_M quantization
ollama pull mistral:latest       # latest (default)

Common quantization levels (smaller = faster, lower quality):

  • Q2_K — smallest, fastest, lowest quality
  • Q4_K_M — good balance, recommended default
  • Q5_K_M — higher quality, slightly larger
  • Q8_0 — near full precision, requires more VRAM
  • fp16 — full precision, largest file

Custom Models with Modelfile

A Modelfile is like a Dockerfile for LLMs. It lets you create a custom model with a system prompt, parameters, and more.

Basic Modelfile

# Modelfile
FROM llama3.2

SYSTEM """
You are a helpful coding assistant specializing in Python.
Always provide working code examples.
"""

PARAMETER temperature 0.7
PARAMETER top_p 0.9
PARAMETER num_ctx 4096

Create and run it:

ollama create my-python-assistant -f ./Modelfile
ollama run my-python-assistant

Modelfile Instructions

Instruction Description
FROMBase model to build from (required)
SYSTEMSystem prompt for the model
PARAMETERSet runtime parameters (temperature, top_p, etc.)
TEMPLATECustom prompt template
MESSAGEPre-seed conversation history
ADAPTERApply a LoRA adapter

Importing GGUF Models

You can import any GGUF model from HuggingFace or local disk:

# Create a Modelfile pointing to your GGUF file
echo 'FROM ./my-model.gguf' > Modelfile

# Import it
ollama create my-custom-model -f Modelfile

# Run it
ollama run my-custom-model

Only GGUF format is natively supported. For SafeTensors or PyTorch models, convert them first using llama.cpp's convert_hf_to_gguf.py.
