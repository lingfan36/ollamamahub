Quickstart

Run your first model, chat via CLI, and make your first API call — in under 5 minutes.

1. Run a Model

Once Ollama is installed, pull and run any model from the library with a single command:

ollama run llama3.2

The first run downloads the model weights. Subsequent runs start instantly from cache. You'll see an interactive prompt:

>>> Send a message (/? for help)

2. Try Other Models

Hundreds of models are available. Here are some popular ones to try:

ollama run mistral

Fast, capable 7B model from Mistral AI

ollama run codellama

Code generation and completion

ollama run phi3

Microsoft's compact 3.8B model

ollama run gemma2

Google's Gemma 2 family

3. Useful CLI Commands

The Ollama CLI has a simple set of commands:

# List downloaded models
ollama list

# Pull a model without running it
ollama pull llama3.2

# Remove a model
ollama rm llama3.2

# Show model info
ollama show llama3.2

# Run with a one-shot prompt
ollama run llama3.2 "Explain quantum entanglement in one paragraph"

4. REST API

Ollama exposes a REST API on http://localhost:11434. Use it to integrate with any language or framework.

Generate a completion

curl http://localhost:11434/api/generate -d '{
  "model": "llama3.2",
  "prompt": "Why is the sky blue?",
  "stream": false
}'

Chat (multi-turn)

curl http://localhost:11434/api/chat -d '{
  "model": "llama3.2",
  "messages": [
    { "role": "user", "content": "Hello! What can you do?" }
  ]
}'

5. Python Example

Install the official Python library:

pip install ollama
import ollama

response = ollama.chat(
    model='llama3.2',
    messages=[{'role': 'user', 'content': 'Why is the sky blue?'}]
)
print(response['message']['content'])

You're all set!
