Installation Guide

Get up and running with Ollama locally on macOS, Windows, and Linux.

macOS

Download the latest version of Ollama for macOS.

Ollama for macOS

Requires macOS 11 Big Sur or later.

Download

Windows preview

Ollama is now available on Windows as a preview.

Ollama for Windows

Requires Windows 10 or later.

Download

Linux

Install Ollama on Linux using the official one-line installation script:

curl -fsSL https://ollama.com/install.sh | sh

A manual installation guide is also available if you prefer not to use the script.

Docker

The official Ollama Docker image is available on Docker Hub.

CPU only

docker run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama

NVIDIA GPU

Install the NVIDIA Container Toolkit, then run:

docker run -d --gpus=all -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama

AMD GPU

To run Ollama using Docker with AMD GPUs, use the rocm tag:

docker run -d --device /dev/kfd --device /dev/dri -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama:rocm

Verify Installation

After installation, verify Ollama is running and pull your first model:

# Check Ollama is running
ollama --version

# Pull and run Llama 3.2
ollama run llama3.2

Default Port

Ollama listens on http://localhost:11434 by default. You can change this with the OLLAMA_HOST environment variable.
