Docker Deployment

A complete guide to containerizing Ollama. Learn how to deploy CPU and GPU containers, manage models via volumes, and write Docker Compose files.

CPU-Only Container

If you don't have a dedicated GPU, you can still run Ollama in a standard Docker container. It will use the CPU for inference, which is sufficient for smaller models or development purposes.

docker run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama

Breakdown:

  • -d: Run in detached mode.
  • -v ollama:/root/.ollama: Persist downloaded models in a Docker volume.
  • -p 11434:11434: Expose the Ollama REST API.

GPU Accelerated Container

For high-performance inference, you should leverage your NVIDIA or AMD GPU. This requires specific container runtime tools depending on your hardware.

NVIDIA GPU

Ensure you have the NVIDIA Container Toolkit installed on your host.

docker run -d --gpus=all -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama

AMD GPU (ROCm)

To run Ollama using AMD GPUs via ROCm, use the specific rocm tagged image:

docker run -d --device /dev/kfd --device /dev/dri -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama:rocm

Docker Compose

For more complex setups, such as running Ollama alongside web UIs like Open WebUI, Docker Compose is the recommended approach.

version: '3.8'

services:
  ollama:
    image: ollama/ollama:latest
    container_name: ollama
    volumes:
      - ollama-data:/root/.ollama
    ports:
      - "11434:11434"
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]

volumes:
  ollama-data:

Run the stack with:

docker-compose up -d
