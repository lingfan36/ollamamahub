Advanced Installation

Learn how to install Ollama manually without curl scripts, set up systemd services on Linux, and customize the installation paths.

Manual Installation (Linux)

If you prefer not to use the automated curl | sh script, you can manually download and install the Ollama binary.

sudo curl -L https://ollama.com/download/ollama-linux-amd64 -o /usr/local/bin/ollama
sudo chmod +x /usr/local/bin/ollama

Create an ollama user to run the service securely:

sudo useradd -r -s /bin/false -U -m -d /usr/share/ollama ollama
sudo usermod -a -G video ollama

Setting up systemd Service

To run Ollama as a background service on Linux, you should configure a systemd unit file.

Create a file at /etc/systemd/system/ollama.service:

[Unit]
Description=Ollama Service
After=network-online.target

[Service]
ExecStart=/usr/local/bin/ollama serve
User=ollama
Group=ollama
Restart=always
RestartSec=3
Environment="OLLAMA_HOST=0.0.0.0:11434"
Environment="OLLAMA_MODELS=/usr/share/ollama/.ollama/models"

[Install]
WantedBy=default.target

Enable and start the service:

sudo systemctl daemon-reload
sudo systemctl enable ollama
sudo systemctl start ollama

Custom Data Paths

By default, Ollama stores models in ~/.ollama/models. You can change this by setting the OLLAMA_MODELS environment variable.

If running as a service, modify the systemd file as shown above. If running manually:

export OLLAMA_MODELS="/mnt/data/ollama/models"
ollama serve
