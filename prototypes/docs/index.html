Installation Guide

Get up and running with Ollama locally on macOS, Windows, and Linux.

macOS

Download the latest version of Ollama for macOS.

Ollama for macOS

Requires macOS 11 Big Sur or later.

Download

Windows preview

Ollama is now available on Windows as a preview.

Ollama for Windows

Requires Windows 10 or later.

Download

Linux

You can easily install Ollama on Linux using our official installation script.

curl -fsSL https://ollama.com/install.sh | sh

The manual installation guide is also available if you prefer to install without the script.

Docker

The official Ollama Docker image is available on Docker Hub.

CPU only

docker run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama

NVIDIA GPU

Install the NVIDIA Container Toolkit, then run:

docker run -d --gpus=all -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama
